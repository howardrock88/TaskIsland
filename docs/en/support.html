TaskIsland Support

If you run into an issue or want to share feedback, please contact the developer through GitHub Issues.

Helpful details to include

  • Your macOS version.
  • Your TaskIsland version.
  • The steps that led to the issue.
  • Screenshots or a screen recording, if available.

GitHub Issues is public. Do not post task contents, Apple Account details, passwords or API keys. Redact sensitive information from screenshots and logs first.

TaskIsland is local-first. No TaskIsland account is required, and task data is stored on your device by default. When iCloud is available, your tasks can synchronize through Apple's private CloudKit database across devices using the same iCloud account.

Checking iCloud sync

In Settings → Sync & Data, confirm sync is enabled. Both devices need the same signed-in Apple Account and compatible app versions with sync support. macOS manages transfers in the background; a local save does not confirm cloud delivery. Keep a network connection and check the latest transfer status. First sync can take time. Turning sync off does not clear your tasks, and troubleshooting does not require uninstalling the app.

Version and system requirements

The redesigned Mac App Store build requires macOS 15 or later and supports Apple silicon and Intel Macs. Today and Daily Review widgets show snapshots, not a live focus timer. File import supports JSON and CSV; export supports JSON, CSV and Markdown.
