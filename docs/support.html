任务岛技术支持

如果你在使用任务岛时遇到问题，或希望反馈建议，请通过 GitHub Issues 联系开发者。

反馈时建议附带

  • macOS 版本。
  • 任务岛版本号。
  • 问题出现的步骤。
  • 如方便，可附带截图或录屏。

GitHub Issues 为公开页面。请勿发布任务原文、Apple 账号、密码或 API Key；截图和日志请先遮挡敏感信息。

任务岛是本地优先工具，不需要任务岛账号，任务数据默认保存在用户本机。iCloud 可用时，使用同一个 iCloud 账号的设备可以通过 Apple CloudKit 私有数据库同步任务。

iCloud 同步排查

在「设置 → 同步与数据」确认同步已开启，两台设备已登录同一 Apple 账号，并使用支持同步的兼容版本。同步由系统在后台执行；保存在本机不等于云端已经接收。保持网络连接，查看最近传输状态；首次同步可能需要等待。关闭同步不会清空任务，也不需要先卸载应用。

版本与系统

新版 Mac App Store 版需要 macOS 15 或更新版本，支持 Apple 芯片和 Intel Mac。小组件提供「今天」和「每日回顾」快照，不提供实时专注计时。文件导入支持 JSON、CSV；导出支持 JSON、CSV、Markdown。
